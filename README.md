### 💼 Experience

**Cyble (YC W21)** — Software Engineer 1 · *Jun 2026 – Present*
Building **Titan**, Cyble's EDR platform, since its earliest days. Built a Kafka pipeline sustaining **500M+ events/day**; fixed I/O-idle CPU with concurrent Go worker pools (**5%→80%** utilization, **10x** fewer servers); ran stateless workers on AWS Spot at 70–90% off; cut duplicate DB writes 90–92% with a Redis dedup layer.

**Zomato (Nugget AI)** — Software Engineer 1 · *Mar 2026 – Jun 2026*
Fixed out-of-order ticket assignments by migrating SQS Standard → FIFO; cut message-size failures by replacing JSON with Protocol Buffers; built a self-healing, RBAC-protected feature-config framework with MQTT propagation and automatic kill switches; swapped ALB for NLB + NGINX for fine-grained TCP control.

**Cyble (YC W21)** — SWE Intern → Software Engineer 1 · *Feb 2025 – Mar 2026*
Engineered an **MCP Server & Client** for AI-driven data exchange between microservices; built an event-lineage / incident-genealogy engine for EDR traceability; cut MS Teams alert latency **45s → 1s** via Kafka + Power Automate; shipped API-triggered endpoint isolation for real-time threat containment.
